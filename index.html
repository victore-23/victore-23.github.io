SF Crime:
Two Decades of Data

This project explores crime-related patterns through visual storytelling, combining static analysis with interactive visualizations built from San Francisco data.

The site highlights relationships in the data, geographic variation across districts, and visual tools that make the trends easier to explore.

Project Notes

About This Site

This page is designed as a responsive single-page portfolio that organizes analysis, visuals, and navigation into a cleaner presentation.

Design goals

  • Dark theme with teal accents for a modern dashboard feel.
  • Clear hierarchy with sections, cards, and strong headings.
  • Responsive layout that works on desktop and mobile.
  • Subtle hover effects and smooth scrolling for polish.

Tools used

This site uses HTML and embedded CSS, plus exported visualization files hosted through GitHub Pages. It serves as a lightweight portfolio for presenting data storytelling work on the web.
